01 Project Overview

What is
LaunchPad?

LaunchPad is a full-stack internship and job opportunity platform built to connect early-career candidates with meaningful roles. The platform presents a curated collection of internships and full-time positions across Engineering, Design, Marketing, Data & Analytics, and Content domains.

Candidates can search, filter, and explore role detail pages with editorial-style content — including company stories, 30-day onboarding timelines, learning outcomes, and culture values — before submitting a guided multi-step application. Employers and administrators access a protected workspace where they can create, edit, and delete listings, and review all incoming applications.

Project Objectives

🎯

Opportunity Discovery

Provide a clean, searchable, and filterable listing of internships and early-career roles that candidates can explore with minimal friction.

📝

Streamlined Applications

Guide candidates through a 3-step application flow with resume upload, cover notes, and submission confirmation.

🏢

Employer Workspace

Give authenticated administrators a secure dashboard to manage listings and monitor incoming applications in real time.

📱

Mobile-First Responsive UI

Ensure the entire platform is fully usable on smartphones and tablets with an adaptive, touch-friendly interface.

02 Features & Functionality

What the
platform does.

For Candidates

1

Search & Filter Opportunities

Search by role title, company name, or keyword. Filter by domain (Engineering, Design, Marketing, Data & Analytics, Content) and job type (Internship, Full-time, Part-time). Results update instantly.

2

Featured Opportunity Spotlight

A highlighted "Opportunity of the Week" card with editorial-style design, company logo, metadata, and a direct call-to-action for high-intent candidates.

3

Editorial Role Detail Pages

Each listing has a full-page editorial profile including: role description, company story, learning outcomes, 30-day onboarding roadmap, culture values, perks, and a sticky application sidebar.

4

Multi-Step Application Form

A guided 3-step application: (1) Profile — name & email, (2) Resume — upload PDF/DOC or paste a link, add cover note, (3) Review & submit. Applications are submitted via authenticated API and stored in MongoDB.

5

User Accounts

Candidates can register and log in. JWT tokens are stored in localStorage and sent with API requests to authenticate submissions.

For Employers & Administrators

A

Protected Admin Workspace

Admins sign in with configured credentials. The admin route is protected server-side by JWT middleware; unauthenticated requests are rejected with a 401 response.

B

Opportunity Management (CRUD)

Create new opportunities via a modal form. Edit existing listings inline. Delete listings with confirmation. All changes persist to MongoDB instantly.

C

Application Inbox

View all submitted applications in a table: applicant name, email, the opportunity applied to, application status, and submission date.

06 Setup & Deployment

Running the
project.

Local Development Setup

1

Clone the repository

git clone https://github.com/keyurpatil2006-sudo/launchpad-job-portal.git

2

Configure environment variables

Copy server/.env.example to server/.env and fill in your MongoDB URI, JWT secret, and admin credentials.

3

Install all dependencies

npm run install:all — installs packages for root, client, and server in one command.

4

Seed the database (optional)

npm run seed — loads initial opportunity data into MongoDB.

5

Start development servers

npm run dev — runs the frontend on port 5173 and the API on port 5000 concurrently.

Environment Variables

# server/.env
PORT=5000
MONGO_URI=mongodb://127.0.0.1:27017/launchpad
JWT_SECRET=replace-with-a-long-random-secret
ADMIN_EMAIL=admin@example.com
ADMIN_PASSWORD=change-me-now
 
# client (Render env var)
VITE_API_URL=https://launchpad-job-portal.onrender.com/api

⚠️ Security note: Never commit your .env file or real credentials to version control. Add server/.env to .gitignore.

08 Conclusion

What was
achieved.

LaunchPad successfully demonstrates a complete, production-deployed MERN stack application covering the full development lifecycle — from local development and database modelling through REST API design, JWT authentication, file handling, responsive UI development, and cloud deployment.

The project prioritises user experience with an editorial design language, smooth animations, and a fully mobile-responsive interface. The employer admin workspace provides real-world CRUD functionality protected by token-based authentication. All changes are version-controlled on GitHub and auto-deployed to Render on every push to the main branch.

This internship project at ATG Technologies provided hands-on experience with every layer of modern web application development — reinforcing skills in React, Node.js, MongoDB, REST API design, responsive CSS, cloud deployment, and collaborative version control.
